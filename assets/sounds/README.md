# Embedded Sounds

These recordings come from Freesound and OpenGameArt and are dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

  | File                     | Original recording                                                                | Creator   |
  | ------------------------ | --------------------------------------------------------------------------------- | --------- |
  | `work-to-break.wav`      | [bell3.wav](https://freesound.org/people/creeeeak/sounds/531026/)                 | creeeeak  |
  | `break-to-work.wav`      | [Street Sign Gong - 03](https://freesound.org/people/robin.kaf/sounds/711881/)    | robin.kaf |
  | `work-to-long-break.wav` | [Subway MTA Door Close Chime](https://freesound.org/people/cbrews/sounds/434085/) | cbrews    |
  | `ticking.wav` | [Ticking clock.](https://opengameart.org/content/ticking-clock) | bart |

The files were converted to 22.05 kHz, mono, 16-bit PCM WAV to reduce their
embedded size. The transition recordings were matched to their sources by
comparing their waveforms with the Freesound previews. The ticking recording preserves bart's
original eight-second loop of eight ticks.
